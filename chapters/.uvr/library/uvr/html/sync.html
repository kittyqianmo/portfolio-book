sync {uvr}R Documentation

Synchronize project library from lockfile

Description

Installs all packages specified in uvr.lock. Idempotent — skips packages that are already installed. Equivalent to uvr sync.

Usage

sync(frozen = FALSE, dir = NULL, quiet = FALSE)

Arguments

frozen

If TRUE, fail if the lockfile is out of date (CI mode).

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output.

Value

Invisible TRUE on success.

Examples

## Not run: 
sync()
sync(frozen = TRUE)  # CI mode: fail if lockfile is stale

## End(Not run)

add {uvr}R Documentation

Add packages to the project

Description

Adds one or more packages to the manifest, updates the lockfile, and installs them. Equivalent to uvr add on the command line.

Usage

add(packages, dev = FALSE, bioc = FALSE, dir = NULL, quiet = FALSE)

Arguments

packages

Character vector of package names (e.g. "ggplot2", "tidymodels@>=1.0.0", "user/repo@main").

dev

If TRUE, add as dev dependencies.

bioc

If TRUE, packages come from Bioconductor.

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output.

Value

Invisible TRUE on success.

Examples

## Not run: 
add("ggplot2")
add(c("dplyr", "tidyr"))
add("DESeq2", bioc = TRUE)
add("user/repo", dev = TRUE)
add("ggplot2@>=3.0.0")

## End(Not run)

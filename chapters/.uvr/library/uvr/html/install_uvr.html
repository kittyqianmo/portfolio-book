install_uvr {uvr}R Documentation

Install the uvr binary

Description

Downloads and installs the uvr binary. By default, tries to download a pre-built binary from GitHub releases. If none is available for the current platform, falls back to building from source via cargo install (requires the Rust toolchain).

Usage

install_uvr(method = c("auto", "binary", "cargo"), force = FALSE)

Arguments

method

Installation method: "auto" (default) tries a pre-built GitHub release binary first, then falls back to building from source via cargo install. "binary" downloads a pre-built binary only. "cargo" builds from source only.

force

If TRUE, reinstall even if uvr is already present.

Value

Invisible path to the installed binary.

Examples

## Not run: 
# Auto-detect best method
install_uvr()

# Force rebuild from source
install_uvr(method = "cargo", force = TRUE)

## End(Not run)

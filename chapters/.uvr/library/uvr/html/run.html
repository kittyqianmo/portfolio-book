run {uvr}R Documentation

Run an R script in the project environment

Description

Executes a script with the project library active. Equivalent to uvr run script.R on the command line. For interactive R, use the CLI directly: uvr run.

Usage

run(script, args = character(), dir = NULL, quiet = FALSE)

Arguments

script

Path to an R script.

args

Character vector of arguments forwarded to the script.

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output.

Value

Invisible TRUE on success.

Examples

## Not run: 
run("analysis.R")
run("model.R", args = c("--seed", "42"))

## End(Not run)

init {uvr}R Documentation

Initialize a new uvr project

Description

Creates a uvr.toml manifest and .uvr/library/ directory. Also generates .Rprofile for RStudio/Positron integration and installs the uvr R companion package. Equivalent to uvr init on the command line.

Usage

init(name = NULL, r_version = NULL, dir = NULL, quiet = FALSE)

Arguments

name

Optional project name. Defaults to the current directory name.

r_version

Optional R version constraint, e.g. ">=4.3.0".

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output.

Value

Invisible TRUE on success.

Examples

## Not run: 
init()
init(name = "my-project", r_version = ">=4.3.0")

## End(Not run)

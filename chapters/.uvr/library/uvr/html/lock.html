lock {uvr}R Documentation

Update the lockfile

Description

Re-resolves all dependencies and writes uvr.lock without installing. Equivalent to uvr lock.

Usage

lock(upgrade = FALSE, dir = NULL, quiet = FALSE)

Arguments

upgrade

If TRUE, upgrade all packages to their latest allowed versions.

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output.

Value

Invisible TRUE on success.

Examples

## Not run: 
lock()
lock(upgrade = TRUE)  # upgrade all packages to latest versions

## End(Not run)

update_pkgs {uvr}R Documentation

Update installed packages to the latest allowed versions

Description

Convenience wrapper that re-resolves the lockfile with lock(upgrade = TRUE) and then installs the updates with sync(). Equivalent to running uvr lock --upgrade && uvr sync on the command line. (uvr-r issue #2.)

Usage

update_pkgs(dir = NULL, quiet = FALSE)

Arguments

dir

Optional working directory. Defaults to getwd().

quiet

If TRUE, suppress output from both phases.

Details

Naming note: this is update_pkgs() rather than update() to avoid masking utils::update(), which has a generic update() for fitted models.

Value

Invisible TRUE on success.

Examples

## Not run: 
update_pkgs()

## End(Not run)
